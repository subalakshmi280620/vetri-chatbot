Coach AI Embed Kit

This page previews the floating Coach AI button on a VIS website. Click the green Coach AI button in the bottom-right corner.

Recommended — add to vetriitsystems.com (before </body>)

One script tag. No duplicate chatbot. Uses the live Render chat UI + Django API.

<script
  src="https://vetri-chatbot-ui.onrender.com/coach-ai-widget.js"
  data-chat-url="https://vetri-chatbot-ui.onrender.com"
  data-title="Coach AI"
  defer
></script>

Local development

With npm run dev on port 5173 and Django on port 8000:

<script
  src="http://localhost:5173/coach-ai-widget.js"
  data-chat-url="http://localhost:5173"
  defer
></script>

Alternative — iframe-only embed (launcher inside iframe)

<iframe
  src="https://vetri-chatbot-ui.onrender.com/?embed=1"
  title="Coach AI — Vetri IT Systems"
  style="position:fixed;right:0;bottom:0;width:400px;height:600px;border:0;background:transparent;z-index:99999;"
  loading="lazy"
></iframe>

After deploying the UI to Render, paste the production script into vetriitsystems.com. CORS already allows vetriitsystems.com on the Django API.
